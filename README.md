# aniversario-namorada

Fundação de uma experiência de aniversário em página única, feita com HTML5, CSS3 e JavaScript puro.

## Estado atual

A primeira etapa implementa somente a fundação visual e técnica:
- layout cinematográfico responsivo;
- navegação entre seções;
- conteúdo centralizado em `js/content.js`;
- módulos separados para aplicação, animações e futuro player;
- placeholders para conteúdo pessoal e mídia;
- documentação de manutenção;
- compatibilidade com GitHub Pages.

Conteúdo pessoal, fotos e músicas reais ainda não foram adicionados.

## Estrutura

```
index.html
css/style.css
js/app.js
js/content.js
js/music-player.js
js/animations.js
assets/fotos/
assets/musicas/
assets/desenhos/
docs/GUIA-DE-EDICAO.md
docs/CHANGELOG.md
```

## Próximas etapas

Novas funcionalidades devem ser adicionadas de forma incremental, seguindo o fluxo:

**analisar → planejar → implementar → testar → revisar → documentar**

Antes de cada etapa, a estrutura existente deve ser auditada para evitar reescritas desnecessárias ou alterações fora do escopo.
